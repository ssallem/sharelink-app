Overview

개요 & 원리

ShareLink는 루팅 없이 안드로이드 폰을 Wi-Fi Direct 핫스팟으로 만들어, PC의 인터넷 트래픽을 폰의 셀룰러 데이터로 중계합니다. 앱 계층의 HTTP/SOCKS5 프록시로 트래픽을 흘려보내기 때문에, 통신사의 시스템 테더링 핫스팟 쿼터와 무관하게 동작합니다.

데이터 경로

동작 4단계

  1. 1

    폰이 Wi-Fi Direct 핫스팟을 엽니다

    폰 앱이 Wi-Fi Direct API(createGroup)로 그룹 소유자(GO)가 되어 DIRECT-SL-… WPA2 핫스팟(legacy 그룹, 일반 AP처럼 비콘 송출)을 엽니다. PC는 보통 Wi-Fi처럼 접속합니다.

  2. 2

    폰 앱이 프록시를 엽니다

    192.168.49.1에서 HTTP CONNECT(8282)·SOCKS5(8283) 프록시를 엽니다. SOCKS5는 RFC 1928 CONNECT(TCP 중계)와 UDP ASSOCIATE(UDP 중계 명령)를 지원해 DNS·QUIC도 받습니다.

  3. 3

    PC는 투명 터널로 전부 보냅니다

    ShareLink.exe는 tun2socks(IP 패킷→SOCKS5 변환 엔진)를 내장하고 wintun 어댑터(10.7.0.2)에 기본 경로 0.0.0.0/0 → 10.7.0.1(metric 1)을 잡습니다. PC 전체 TCP/UDP가 SOCKS5로 가고 DNS(8.8.8.8)도 UDP로 터널되어 DoH(DNS over HTTPS)가 필요 없습니다.

  4. 4

    셀룰러 소켓으로 재발신합니다

    셀룰러 전용 Network(requestNetwork)에 요청마다 소켓 단위로 개별 바인딩(프로세스 전체가 아님)합니다. 폰 앱의 일반 데이터로 나가며 IPv4를 우선합니다.

알아두기

왜 루팅이 필요 없나 — 공개 Android API(Wi-Fi Direct·ConnectivityManager)와 일반 소켓 서버만 사용합니다.
왜 시스템 테더링 쿼터와 무관한가 — 위 원리대로 OS 테더링이 아닌 폰 앱 트래픽으로 분류되기 때문입니다. 요금제·약관 준수 책임은 사용자에게 있습니다.
한계 — IPv6 미지원(IPv4만 처리). 폰의 배터리 소모·발열 증가. 속도는 폰 셀룰러 품질에 종속됩니다.
무루팅 (No-root) 테더링 쿼터 무관 앱별 설정 없이 전체 트래픽 투명 터널 모드 내장

Usage

사용법 — 2가지 모드

간단히 브라우저만 폰 데이터로 쓰려면 모드 1, PC 전체를 폰 데이터로 쓰려면 모드 2를 사용하세요.

Mode 1 · 프록시

프록시 (간단, 설치 0)

PC의 Windows 프록시 설정에 아래 값을 넣으면, 브라우저와 프록시를 지원하는 앱이 폰 데이터로 연결됩니다.

HTTP 프록시 서버 192.168.49.1 · 포트 8282
SOCKS5 프록시 서버 192.168.49.1 · 포트 8283
Mode 2 · 투명 터널

투명 터널 (모든 앱, 무프록시)

ShareLink.exe를 실행하고 트레이에서 켜기만 하면, PC의 전체 TCP/UDP 트래픽이 프록시 설정 없이 폰 데이터로 흐릅니다.

  • tun2socks 내장 — 앱마다 프록시를 설정할 필요가 없습니다.
  • DNS와 QUIC까지 터널되므로 별도의 DoH 설정이 불필요합니다.
  • IPv6는 지원하지 않습니다(터널은 IPv4만 처리). IPv6 우선 사이트는 느려질 수 있습니다.

Phone Setup

폰 설정 — 3스텝

  1. 폰에서 ShareLink 앱 실행 → 시작 Wi-Fi 라디오 ON(어딘가에 연결할 필요는 없음) + 모바일 데이터 ON 상태로 앱의 시작 버튼을 누릅니다.
  2. PC Wi-Fi를 폰 핫스팟에 연결 PC에서 DIRECT-SL-… 로 시작하는 Wi-Fi에 연결합니다. 암호는 앱 화면에 표시된 암호를 입력하세요. (“인터넷 없음” 표시는 정상입니다.)
  3. 연결됐는데 인터넷이 안 되면: MAC 랜덤화 끄기 해당 Wi-Fi의 “임의(랜덤) 하드웨어 주소 사용” 끄기(MAC 랜덤화 OFF). 자주 겪는 문제이며, 이 설정만 꺼도 대부분 해결됩니다.

Troubleshooting

문제해결

연결은 되는데 인터넷이 안 돼요
PC에서 해당 Wi-Fi의 MAC 랜덤화(임의 하드웨어 주소)를 끄세요. 가장 흔한 원인입니다. 폰의 모바일 데이터가 켜져 있는지도 함께 확인하세요.
192.168.49.1:8283에 도달할 수 없다고 나와요
폰의 ShareLink 앱이 “시작” 상태인지, PC가 DIRECT-SL-… Wi-Fi에 실제로 연결돼 있는지 확인하세요. 다른 Wi-Fi에 붙어 있으면 폰에 도달하지 못합니다.
비정상 종료 후 PC 인터넷이 끊겼어요
ShareLink.exe를 다시 실행하면 라우팅·프록시 설정이 자동으로 복구됩니다. 재부팅은 필요 없습니다.
실행 시 SmartScreen 경고가 떠요
이 앱은 EV(확장 검증) 코드서명 인증서로 서명되어 있습니다(JCG Inc., DigiCert). 대부분 경고 없이 실행되지만, 드물게 경고가 뜨면 “추가 정보 → 실행”을 눌러 진행하세요.
