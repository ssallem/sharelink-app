개인정보처리방침 — ShareLink

시행일: 2026년 11월 11일
앱: ShareLink (휴대폰 인터넷 연결 공유), 패키지 com.vravio.sharelink, 버전 0.5.0
사업자: Vravio Inc
문의: app@binah.team

ShareLink는 이용자의 개인정보를 수집하지 않습니다. 회원가입·로그인이 없고, 사업자가 운영하는 서버가 없으며, 광고·분석·추적 기술도 없습니다. 연결된 기기의 인터넷 트래픽은 휴대폰을 거쳐 그대로 전달될 뿐, 그 내용을 저장하거나 사업자에게 보내지 않습니다.

1. 앱의 동작과 트래픽 처리

ShareLink는 이용자가 켰을 때에만 휴대폰에 Wi-Fi Direct 그룹(임시 무선망)과 기기 내 프록시(HTTP·SOCKS5)를 열어, 이용자가 직접 연결한 노트북·태블릿 등이 휴대폰의 인터넷 연결을 함께 쓰도록 중계합니다.

  • 중계되는 트래픽의 내용은 저장·기록·분석하지 않습니다. 화면 통계를 위해 기기별로 주고받은 데이터 양(바이트 수)만 셉니다.
  • HTTPS 연결은 연결된 기기와 목적지 서버 사이에서 암호화된 상태 그대로 전달되며, 앱은 그 내용을 볼 수 없습니다.
  • 트래픽은 사업자 서버를 거치지 않고, 휴대폰의 통신망에서 목적지로 직접 나갑니다.

2. 수집하는 개인정보

없습니다. 사업자(Vravio Inc)는 어떠한 개인정보도 수집·전송·판매·공유하지 않습니다.

3. 기기 내부에만 저장되는 정보

  • 설정 — 무선망 이름 접미사, 무선망 암호, 프록시 포트, 나가는 경로(모바일 데이터/기본 네트워크), 데이터 한도, 유휴 자동 종료 시간
  • 사용 기록 — 공유 세션별 시작·종료 시각, 사용 시간, 주고받은 데이터 양, 최대 연결 기기 수, 종료 사유, 연결 기기의 내부 IP 주소(예: 192.168.49.x)와 사용한 방식(HTTP/SOCKS5)별 데이터 양. 최근 300건(1MB)까지만 보관하고 오래된 것부터 지웁니다. 방문한 사이트 주소나 내용은 기록하지 않습니다.

이 정보는 사업자나 제3자에게 전송되지 않습니다. 사용 기록의 내보내기는 이용자가 직접 누를 때만 안드로이드 공유 화면을 통해 이용자가 고른 앱으로 전달되며, Wi-Fi 접속용 QR 코드는 기기 안에서 만들어집니다.

파기 방법앱의 기록 "삭제", 앱 삭제, 기기 설정의 앱 데이터 삭제 (별도 보관본 없음)
제3자 제공 · 처리위탁없음

5. 안드로이드 자동 백업 고지

ShareLink는 안드로이드 표준 자동 백업을 허용합니다. 이용자가 기기에서 백업을 켜 둔 경우, 위 설정과 사용 기록이 이용자 본인의 Google 계정 백업에 포함될 수 있으며 Vravio Inc는 접근할 수 없습니다. 원하지 않으시면 기기의 설정 → Google → 백업에서 끌 수 있습니다.

6. 권한과 사용 목적

  • 인터넷 · 네트워크 상태 · 네트워크 변경(INTERNET, ACCESS_NETWORK_STATE, CHANGE_NETWORK_STATE) — 연결된 기기의 트래픽을 휴대폰의 모바일 데이터로 중계합니다.
  • Wi-Fi 상태 · 변경 · 근처 기기(ACCESS_WIFI_STATE, CHANGE_WIFI_STATE, NEARBY_WIFI_DEVICES) — Wi-Fi Direct 그룹을 만들기 위해 사용합니다. 근처 기기 권한은 위치를 얻지 않는다고 선언(neverForLocation)되어 있습니다.
  • 정확한 위치(ACCESS_FINE_LOCATION, 안드로이드 12 이하에서만) — 해당 버전의 안드로이드가 Wi-Fi Direct 사용에 이 권한을 요구하기 때문에 요청합니다. 앱은 위치 정보를 읽거나 저장하지 않습니다.
  • 알림(POST_NOTIFICATIONS) — 공유 중 상태와 사용량, 데이터 한도 알림을 표시합니다.
  • 포그라운드 서비스 · 화면 꺼짐 유지(FOREGROUND_SERVICE, FOREGROUND_SERVICE_CONNECTED_DEVICE, WAKE_LOCK) — 화면을 꺼도 연결된 기기의 인터넷이 끊기지 않게 합니다. 공유를 끄면 함께 종료됩니다.

7. 광고 및 추적

광고를 표시하지 않습니다. 광고·분석·크래시 리포팅 SDK를 포함하지 않으며 Android 광고 ID를 사용하지 않습니다.

8. 아동의 개인정보

ShareLink는 만 13세 미만 아동을 대상으로 하지 않으며, 어떤 연령의 이용자로부터도 개인정보를 수집하지 않습니다.

9. 정보주체의 권리 및 데이터 삭제 방법

  • 사용 기록 삭제 — 앱 홈 화면 "기록" 패널의 "삭제"
  • 전체 삭제 — 앱 삭제 또는 설정 → 애플리케이션 → ShareLink → 저장공간 → 데이터 삭제
